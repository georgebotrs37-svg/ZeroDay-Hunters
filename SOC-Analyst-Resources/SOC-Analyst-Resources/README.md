## The Roadmap Overview

Cloud engineering is about **building, deploying, securing, and scaling infrastructure in the cloud**.

This roadmap starts with **core IT foundations**, moves into **cloud providers & services**, then covers **DevOps, Infrastructure as Code, architecture**, and finally **advanced cloud topics**.

- [Phase 1: Foundations](#phase-1-foundations)
